admin hierarchy rule set:

USER
- Access regions only
- Can see admins
- Cannot affect anyone

ADMIN
- Can affect USER accounts
- Can downgrade/affect ADMIN accounts
- Cannot see or affect SUPERADMIN accounts

SUPERADMIN
- Can affect USER and ADMIN accounts
- Cannot affect other SUPERADMIN accounts through the API
- Other SUPERADMIN conflict is handled via headed access
